# Product Usability Task Classes

Use these classes to set QA step budgets and decide whether AI assistance is appropriate.

## Simple, No AI Required

- create a basic record
- add a contact
- add a location or address
- search for and open a record
- edit phone, email, name, or other basic fields
- assign an existing person to existing work
- schedule existing work
- send an item for review or approval
- approve or reject an item
- mark work status
- view communication or activity history

Expected budget: 3-5 steps. More than 7 is a Usability bug. 10+ is Severe Usability.

## Medium, Guided UI Expected

- create an estimate, proposal, order, or comparable business object
- add several normal catalog or pricebook items
- schedule approved work
- invite a user with a role
- configure company profile
- configure customer-facing branding
- triage a workflow inbox item

Expected budget: 6-12 steps. More than 15 is a Usability bug. 20+ is Severe Usability.

## Complex, AI Assist Appropriate

- write business rules
- design packages or templates
- design workflow automations
- configure provider compliance or readiness
- map imports
- build marketing campaigns
- configure advanced integrations

Expected budget: 15-30 steps may be acceptable only when the flow is guided, previewable where applicable, recoverable, and appropriate for advanced configuration.
